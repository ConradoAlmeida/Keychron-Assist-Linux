# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes       |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Send the details to **conrado.almeida@outlook.com** with:

- the affected version (`kassist --version`);
- the distribution and desktop (Debian/Ubuntu/Fedora, GNOME/KDE, Wayland/X11);
- a description and, if possible, reproduction steps.

I aim to reply within 7 days and to coordinate the fix and disclosure with you.
For non-security bugs and feature requests, use the
[GitHub Issues](https://github.com/ConradoAlmeida/Keychron-Assist-Linux/issues).
