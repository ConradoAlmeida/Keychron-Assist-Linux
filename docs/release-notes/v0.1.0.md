# kassist 0.1.0

First public release: an unofficial local helper for the Keychron Launcher on
Linux. It serves the app list to <https://launcher.keychron.com>, stores the
Quick Start bindings and opens the bound app when the keyboard key fires.

## What works

- **GNOME backend**: custom shortcuts (F16–F18 on xkeyboard-config 2.42,
  F16–F19 on 2.47); the daemon needs no root.
- **evdev backend** (`--udev`): all 5 slots, independent of XKB.
- Validated end-to-end with a Keychron V6 Max on Debian 13 GNOME, Ubuntu 24.04
  and Debian 13 KDE (Plasma 6.3.6), all Wayland.
- Diagnostics: `kassist doctor` and `tools/selftest.py` (with `--simulate`).

## Install

Debian/Ubuntu:

```bash
sudo apt install ./kassist_0.1.0_all.deb
kassist-setup
```

Fedora:

```bash
sudo dnf install ./kassist-0.1.0-1.fc44.noarch.rpm
kassist-setup
```

From source: `./install.sh` (see the README).

## Notes

- **Ubuntu**: use Google Chrome from the `.deb`; the Chromium snap cannot open
  `/dev/hidraw` (WebHID). `install.sh` detects this and offers Chrome
  (`--browser`).
- GNOME mode has 3 slots on Debian 13/Ubuntu 24.04 (no `<FK19>`); use
  `--udev` for 5.
- 2.4 GHz receivers are not mapped; use the cable.
- Unofficial, not affiliated with Keychron.
